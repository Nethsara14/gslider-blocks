Welcome to the official **GSlider Blocks Design System & Storybook** for [GSlider Blocks](https://github.com/noruzzamans/gslider-blocks), built in alignment with WordPress Gutenberg Block Editor standards.

GSlider Blocks is an enterprise-grade WordPress Gutenberg carousel and slider block suite built with modern React, pure Swiper.js, and a robust decoupled PHP backend architecture.

---

## 🎯 Mission Statement

Our mission is to provide WordPress creators, agencies, and enterprise site builders with a high-performance, accessible, and intuitive slider design toolkit that produces **zero client-side bloat**, enforces **GDPR-compliant local assets**, and delivers **100% lean inline styles**.

---

## 🏛️ Comprehensive Component Registry (22 Core Controls + 1 Composition)

The GSlider Block Editor design system consists of **22 battle-tested UI controls** in `src/components/` built strictly for the WordPress Block Inspector sidebar (280px–300px width), showcased across **20 isolated component stories and 1 full inspector composition** in Storybook.

## 🔒 Protected Core Policy

> **CRITICAL ARCHITECTURAL RULE:**

No external PR or AI assistant is permitted to modify or create files in `src/components/` without explicit authorization from `@noruzzamans`. All new stories and experimental compositions belong exclusively inside `storybook/stories/`.

## 🚀 Getting Started with Storybook

To run the local component explorer in development mode:

```bash
npm run storybook
```

To compile the production static distribution for deployment on GitHub Pages:

```bash
npm run storybook:build
```
