# 🎠 GSlider Blocks Design System & Component Library

Welcome to the official **GSlider Blocks Design System & Storybook**, modeled directly after the [WordPress Gutenberg Storybook](https://wordpress.github.io/gutenberg).

GSlider Blocks is an enterprise-grade WordPress Gutenberg carousel and slider block suite built with modern React, pure Swiper.js, and a robust decoupled PHP backend architecture.

---

## 🎯 Mission Statement

Our mission is to provide WordPress creators, agencies, and enterprise site builders with a high-performance, accessible, and intuitive slider design toolkit that produces **zero client-side bloat**, enforces **GDPR-compliant local assets**, and delivers **100% lean inline styles**.

---

## 🚀 Getting Started with Storybook

To run the local component explorer in development mode:

```bash
npm run storybook
```

To compile the production static distribution for deployment on GitHub Pages:

```bash
npm run storybook:build
```
