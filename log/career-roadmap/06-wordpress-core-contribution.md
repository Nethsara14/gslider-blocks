## Contribution Level Up Plan

### Level 1: Bug Fixes & Small PRs (আপনি এখানে আছেন ✅)
- CSS fixes, DocBlock fixes, small PHP fixes
- **Impact:** Low-Medium
- **Difficulty:** Easy

### Level 2: Feature Contributions
- নতুন feature propose করা
- Existing feature improve করা
- **Example areas:**
  - Gutenberg block editor improvements
  - Admin UI enhancements
  - REST API improvements
- **Impact:** Medium-High
- **Difficulty:** Medium

### Level 3: Component Maintainer
- একটা specific component own করুন
- Regular reviews দিন
- **Target areas for you:**
  - Block Editor (Gutenberg) — আপনি block development করেন
  - Admin UI — আপনি admin reskin tickets করেছেন
- **Impact:** High
- **Difficulty:** Medium-High

### Level 4: Core Committer
- Long-term goal
- Requires sustained contribution + trust
- **Impact:** Very High

## কোথায় Focus করবেন?

### Gutenberg / Block Editor (Best Fit for You)
আপনি daily block development করেন, তাই Gutenberg contributions সবচেয়ে natural:

1. **GitHub:** [github.com/WordPress/gutenberg](https://github.com/WordPress/gutenberg)
2. **"Good first issue" label** দিয়ে শুরু করুন
3. **Block Editor components** improve করুন
4. **Accessibility fixes** — always welcome

### Trac Tickets
1. [core.trac.wordpress.org](https://core.trac.wordpress.org/)
2. Filter: "has-patch needs-testing" — এগুলো test করুন
3. Filter: "good-first-bug" — easy picks
