## 🛠️ Feature Breakdown

### 1. 🧩 Core Updates (Easy Wins)
*Foundation for stability and quick features.*

- [ ] **Rename Block:** `Image Carousel` -> `Image Slider` (SEO best practice).
- [ ] **Random Order:** Add PHP `shuffle()` logic to `render_callback`.
- [ ] **Fill Modes:** Ensure `cover`, `contain`, `stretch` CSS classes work perfectly.
- [ ] **Multilingual Hooks:** Add `apply_filters()` to caption/attributes for WPML support.

### 2. 🦸 Hero Mode (The "Wow" Factor)
*Center slide zoomed in. The main marketing hook.*

- [ ] **Swiper Config:** Enable `centeredSlides: true`, `slidesPerView: 'auto'`.
- [ ] **CSS Transform:** Add scale effect (`transform: scale(1.2)`) to `.swiper-slide-active`.
- [ ] **Opacity Fade:** Reduce opacity of non-active slides (`opacity: 0.5`).
- [ ] **Inspector Control:** Add toggle `Enable Hero Mode` in Settings.

### 3. 🔄 Hover Image Switch (Product/Portfolio)
*Show secondary image on hover.*

- [ ] **Attribute Update:** Add `hoverImage` attribute to block config.
- [ ] **Media Upload:** Add second image upload slot in Inspector.
- [ ] **Frontend Render:** Output both images, toggle visibility via CSS on hover.

### 4. 🖼️ Lightbox (Lite Version)
*Essential for image viewing.*

- [ ] **Integration:** Integrate simple Lightbox library (e.g., GLightbox or simple CSS modal).
- [ ] **Toggle:** Add `Enable Lightbox` in Link Settings.
- [ ] **Asset Loading:** Ensure scripts only load when block is present.
